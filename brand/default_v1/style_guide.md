# Style guide (default_v1)

Tone: plain, confident, specific. Write for the audience named in the brief. No hype, no filler.

## Content rules
- One message per slide. The title STATES the message as a short sentence (5-9 words), sentence case, no trailing period.
- Max 4 bullets per list, max 14 words per bullet. Detail belongs in speaker notes (2-4 sentences), not on the slide.
- Every factual claim traces to a finding id in `source_refs`. Never state anything the cited findings do not support.
- Numbers on slides (stats, charts, years) must appear in the cited findings. Mark approximate figures in the chart title (for example "Approximate peak power (hp)").
- Never invent a source, a figure, a quote or a date. If the findings are thin, show less.
- Titles never end in a period. Do not use em dashes.

## Design rules (the renderer enforces geometry; you choose structure)
- Vary layouts: never use the same composition three slides in a row.
- Every content slide carries a visual element: stats, cards, timeline, comparison, icon rows, a chart, or a table.
- Use stat callouts for 2-4 headline numbers, timelines for sequences of dated events, comparison for two sides, a chart for numeric comparisons across categories.
- Icons: react-icons Font Awesome names (prefix Fa), for example FaCarSide, FaBolt, FaFlagCheckered, FaShieldAlt, FaTrophy, FaCogs, FaUsers, FaHistory, FaGlobe, FaBook.
- Stay within the character limits given for each field. Cut words; never ask for a smaller font.
